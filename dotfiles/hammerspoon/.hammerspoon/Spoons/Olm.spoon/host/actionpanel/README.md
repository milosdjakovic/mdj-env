# ActionPanel

A searchable list of the verbs the chooser already on screen can run, borrowed for as long as
the panel stays open. It never lists navigation, the shared moving, inserting, closing, and
scrolling every list already carries, only the actions a person forgets the chord for.

It reaches over whatever chooser is open rather than owning one of its own, swapping that
chooser's rows for its own list of verbs and restoring the original list, on the row it was
opened over, the moment a verb runs or the panel closes. Its rows, and what running one does,
are asked of the composition root, so the panel itself never learns what a verb is called or
what it does.

Opens on Hyper and the period key, over any list already showing.
