# HyperCheatSheet

Draws the overlay that appears while Caps Lock, the Hyper leader, is held. The apps bound to
their own letter come first, split into the ones already running and the ones that are not,
and every other chord bound on the leader follows as its own section. Each part is supplied to
it, the app sections by the app toggler and the chords by the composition root, so the overlay
lists exactly what the leader does and nothing else.

It has no key of its own. Holding the leader reveals it and releasing the leader hides it
again. Drawing is delegated to the shared overlay renderer both cheat sheets draw through.
