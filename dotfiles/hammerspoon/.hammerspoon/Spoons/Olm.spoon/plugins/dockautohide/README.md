# DockAutoHide

Turns the Dock's own auto hide setting on or off, and switches its show delay
between instant and the macOS default. Reached as a page of two rows inside the
launcher, hiding first then delay, each row naming the action choosing it takes
rather than the state the Dock happens to be in right now. Changing the delay
restarts the Dock so the change is actually seen, hiding takes effect at once
with no restart.

There is no dedicated chord, it opens only from its own row in the launcher, and
can be searched without leaving the launcher by typing d or dock.
