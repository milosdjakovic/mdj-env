# Browser Switcher

With Olm as the default browser, every link you click comes here. A rule you wrote opens it at once
in the browser or profile it names. Otherwise a list asks which one, your favourites in your own
order, Copy Link among them, and Show All in the actions pane lists every browser and profile this
Mac has. Holding Option as you click always asks.

Favourites, rules and the default browser are set on its own page in Olm Settings, under Plugins,
where choosing Olm as the default browser is answered by macOS's own question.
The launcher row Browser Switcher opens the last link again, to send it somewhere else.

Return opens the link in the highlighted browser, Command and Return copies it.
