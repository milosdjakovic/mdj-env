# Browser Switcher

With Olm as the default browser, every link you click comes here and a list asks where it opens,
your favourites, a browser, one of its profiles or Copy Link, and Show All in the actions pane lists
every browser and profile this Mac has.

The default browser and the favourites are set on its own page in Olm Settings, under Plugins,
where choosing Olm as the default browser is answered by macOS's own question. The launcher row
Browser Switcher opens the last link again, to send it somewhere else.

Return opens the link in the highlighted browser, Command and Return copies it.
