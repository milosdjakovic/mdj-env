# TextCase

Recases whatever text is currently selected. Each row is titled in the case it
offers and previews your own selection rendered that way, so you see the real
result rather than a generic example, and choosing one pastes it back over the
selection in place.

Reached from the launcher only, with no dedicated chord, and it cannot be scoped
by an alias since a narrowed list has no way to read the selection it exists to
preview.

While the list is open, j and k move, i applies the highlighted case, and x
closes it.
