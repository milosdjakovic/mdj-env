# FileSearch

Finds a file by name and does something with it. Typing a name searches
everywhere at once, a slash after a folder searches or browses inside it, a dot
in front of a word filters by file type, and a lone dot reaches the files macOS
refuses to index. The list remembers what you actually open, copy, or reveal, so
a file you reach for often rises even when it has not changed lately.

Opens on Hyper and slash, appears in the launcher under Tools, and can be
searched without leaving the launcher by typing a slash.

While the list is open, j and k move, i opens the highlighted file, l goes into a
folder and h comes back up, o reveals it in Finder, y copies its path, q shows a
quick preview when one is available, and x closes the list.
