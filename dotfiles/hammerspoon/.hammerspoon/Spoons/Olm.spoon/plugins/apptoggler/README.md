# AppToggler

Shows or hides an application, or brings it forward and cycles through its windows
when it is already the frontmost app. A toggle can also open straight to one
settings pane by its url instead of a plain focus, which is how the System
Settings toggle lands on General.

Each app is bound to its own chord on the Hyper leader, holding Caps Lock and
pressing the app's own letter. The whole set also appears as rows in the
launcher's application list, reached by typing a or app to narrow to only those
rows.

There are no other keys. Holding the same chord again toggles the app back to
hidden.
