# Wifi

Shows the Wi-Fi network this Mac is on and every network in range. Choosing the current
network disconnects from it, and choosing any other joins it, with the saved password where
the system has one and a password prompt where it does not. Saved networks are listed first,
then the rest by signal. A scan runs each time the list opens and the last one stays on
screen until it lands.

Opens from the launcher under Network, and can be searched without leaving the launcher by
typing wi or wifi.

While the list is open, i joins or disconnects the highlighted network and x closes it.
