# DisplayProfiles

Keeps a saved display arrangement applied automatically whenever the attached
monitors match one, correcting the wrong main display or the wrong scaling a dock
can leave behind. It also inspects and manages those arrangements, listing every
profile, marking the one currently active, and letting you capture the current
arrangement under a new name, rename a captured one, or delete it. Only captured
profiles can be edited, the hand written ones stay read only.

Opens only from the launcher, with no dedicated chord and no alias of its own.

While the list is open, j and k move, i selects the highlighted row or drills into
it, and x closes the whole thing.
