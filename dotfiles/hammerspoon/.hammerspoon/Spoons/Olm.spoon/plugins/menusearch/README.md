# MenuSearch

Lists every menu bar item of whichever app is frontmost, currently disabled ones
included, read straight from macOS accessibility, and runs the highlighted one
the same as clicking it in the menu bar. A keyword finds a command without
knowing which menu it lives under. Choosing an item that is disabled at that
moment does nothing, the same as clicking it dimmed.

Opens on Hyper and E, and can be searched without leaving the launcher by typing
m or menu, though it has no row of its own on the launcher's default list, only
the alias reaches it there.

While the list is open, j and k move, i runs the highlighted item, and x closes
it.
