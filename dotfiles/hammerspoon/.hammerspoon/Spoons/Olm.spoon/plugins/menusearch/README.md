# MenuSearch

Lists every enabled menu bar item of whichever app is frontmost, read straight
from macOS accessibility, and runs the highlighted one the same as clicking it in
the menu bar. A keyword finds a command without knowing which menu it lives
under.

Opens on Hyper and E, and can be searched without leaving the launcher by typing
m or menu, though it has no row of its own on the launcher's default list, only
the alias reaches it there.

While the list is open, j and k move, i runs the highlighted item, and x closes
it.
