# Convert

Converts a typed quantity from one unit or currency to another and offers the
answer as a row inside the launcher's own search, the same way Arithmetic offers
a sum. A query only counts as a conversion when it carries a number and names a
target after the word to, such as ten kilometres to miles, so an ordinary search
never runs the calculator behind it.

It needs an external calculator tool. Without one, Convert simply does not appear
among the launcher's sources, and the console says once that it is missing, while
Arithmetic keeps answering plain sums regardless.

It is not a picker and opens nothing of its own, there is no chord and no
launcher alias, it only ever shows up as a row while typing in the ordinary
unscoped launcher list.

Since typing is the only way to find it, it proposes one short example line for the
launcher's empty field, which the launcher shows on some of its opens in place of its
own wording. A machine without the calculator tool never sees that line either, so the
field advertises nothing it cannot answer.
