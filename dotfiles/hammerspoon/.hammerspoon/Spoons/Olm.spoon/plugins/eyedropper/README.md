# ColorPicker

Turns the pointer into the native macOS colour sampler, the same magnifier loupe
the system's own colour pickers use. Clicking copies the sampled pixel's hex
value to the clipboard, Escape cancels without copying anything.

Opens on Hyper and 2, and appears in the launcher under Tools as Color picker. It
is not a list and has no launcher alias, there is nothing to search or navigate
once it is open, only the click and the cancel.
