# Processes

Finds the development servers, containers, and background watchers you left
running, identified by the port they hold and the project directory they run in
rather than by process name, and stops the whole process group or container
rather than one leaf process. The launcher shows it as Local Servers rather than
Processes, since it lists only what you started rather than the whole process
table.

Reached from the launcher only, with no dedicated chord.

While the list is open, j and k move, i stops the highlighted row, s reorders the
list by live load, f force stops with no grace period, r rescans in place, and x
closes the list.
